# 🛒 Olist E-Commerce Sales Analytics Dashboard

An interactive **Power BI dashboard** built to analyze Olist e-commerce sales, customers, products, orders, payments, states, and delivery performance.

This project demonstrates my skills in **Power BI, DAX, Power Query, Data Cleaning, Data Modeling, and Data Visualization**.

---

## 📊 Dashboard Overview

The dashboard consists of **5 interactive pages**:

### 📌 Page 1 – Olist Sales Overview

- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Monthly Sales Trend
- Top 10 States by Sales
- Orders by Status
- Payment Method Distribution
- Sales by Product Category
- Average Delivery Time
- Interactive Filters
